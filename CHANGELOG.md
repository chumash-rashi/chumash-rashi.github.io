# Changelog

Version number is shown in the footer of every page (`APP_VERSION` in each Rashi-*.html). To release: bump `APP_VERSION`, add an entry here, commit, then `git tag vX.Y.Z` and push the tag to both remotes (`origin` and `pages`).

Feedback: the footer "Feedback" link opens a pre-filled GitHub issue at https://github.com/yishairasowsky/chumash_rashi/issues (needs a free GitHub account).

## 1.8.3
- Pasuk font changed to Taamey Frank CLM (Culmus project; GPL with font-embedding exception), hosted in `fonts/`. Cardo remains as fallback. Chosen after feedback from Yossi Zahn that he preferred Taamey Frank CLM or SBL Hebrew.

## 1.8.2
- Pasuk font changed to Cardo (a scholarly font with proper cantillation-mark placement); falls back to Frank Ruhl Libre. Applies to the on-screen pasuk and the printed test. Feedback from Yossi Zahn.

## 1.8.1
- Fix: Vayishlach and Vayeshev now highlight the key phrase in Rashi's text after answering (it was missing).

## 1.8.0
- New parsha: Vayeshev (Bereishis 37:1 – 40:23), same format (Hebrew with niqqud, English version, printable test).

## 1.7.0
- New parsha: Vayishlach (Bereishis 32:4 – 36:43), 168 Rashis, Hebrew with full niqqud plus English version and printable test.

## 1.6.1
- Printable Hebrew test: full niqqud everywhere, including the Rashi headings (dibbur hamaschil), page title, labels (name/date/score), and the answer-key heading. Requested for a young reader.
- Footer (version, feedback, language, print) about 30% larger.

## 1.6.0
- English version of every parsha: footer button switches between עברית and English (remembered). English questions, choices, plain-English explanation of each Rashi, English pasuk and Rashi (Metsudah via Sefaria, CC-BY); layout flips to left-to-right.
- Printable test with answer key: footer "Print test + answer key" (whole parsha or one chapter, in the current language). Questions with lettered choices first, answer key (letter, correct answer, Rashi reference, explanation) on the last pages. Suggested by Yaakov.
- Quote marks: all quotes next to Hebrew now use ״ so opening and closing marks render the same.
- Generated by `add_english.py` (translations are in each page's `EN` constant).

## 1.5.0
- Lech Lecha and Vayera rebuilt to the same standard as Toldot and Vayetze: new Hebrew questions with full niqqud, Hebrew explanation of each Rashi, highlighted key phrases, clean Rashi text (old garbled strings removed). Progress for these two parshiyot restarts because the questions changed.
- Chayei Sarah: Hebrew explanation of each Rashi (the "Rashi's language" button previously showed English).
- Quoted words in questions now take the pasuk's vowels even when the quote drops a prefix letter (e.g. בַּשָּׁנָה quoted as "שָׁנָה") or follows a prefix like בְּ.
